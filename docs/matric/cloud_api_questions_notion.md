## Q06. 조건 추론과 역방향 추론 방지

- **난이도**: 추론 필요
- **카테고리**: 논리 추론
- **평가 능력**: 조건 추론, 논리적 일관성, 역방향 추론 방지, 불확실한 결론의 보류

**질문**

> 다음 정보만 사용하세요. 모든 정회원은 출입카드가 있습니다. 지수는 정회원입니다. 민수는 출입카드가 있습니다.
> A. 지수는 출입카드가 있다.
> B. 민수는 정회원이다.
> C. 지수는 출입카드가 없다.
> 각 문장이 반드시 참이면 "참", 반드시 거짓이면 "거짓", 참과 거짓이 모두 가능하면 "판단불가"로 분류하세요. 설명 없이 "A=분류", "B=분류", "C=분류" 형식으로 세 줄을 쓰세요.

**기대 답변(예시)**

> A=참
> B=판단불가
> C=거짓

**내용 체크포인트**

- [ ] 정회원인 지수에게 출입카드가 있음을 올바르게 추론함
- [ ] 출입카드가 있다는 사실만으로 민수가 정회원이라고 역추론하지 않음
- [ ] 지수에게 출입카드가 없다는 명제를 거짓으로 분류함

**형식 기준**

- [ ] 지정된 A, B, C 순서로 세 줄을 작성함
- [ ] 분류에는 "참", "거짓", "판단불가"만 사용함
- [ ] 추가 설명을 붙이지 않음

**명백한 오답 기준**

- 민수가 반드시 정회원이라고 결론 냄
- 민수가 반드시 비회원이라고 결론 냄
- 지수에게 출입카드가 없을 수도 있다고 판단함

**채점 배점**: 내용 2점 + 형식 1점 = 총 3점
