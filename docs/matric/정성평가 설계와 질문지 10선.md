# 정성평가 설계와 질문지 10선

## 평가 기준과 질문 선정 이유

이번 테스트는 한국어가 공통어로 사용되는 공공기관·기업 환경에서 로컬 LLM을 실제로 활용할 수 있는지 확인하는 데 목적이 있습니다.

### 1. 평가 기준

생성형 언어모델은 같은 정답이라도 표현 방식이 다를 수 있어, 정답 문장과 완전히 일치하는지만으로 평가하기는 어렵습니다. 그래서 실험 전에 문항별 평가 기준을 따로 정하고, 모든 모델에 동일한 기준을 적용했습니다. 평가 기준은 다음 세 가지로 나뉩니다.

| 기준 | 설명 |
| --- | --- |
| content_checkpoints | 답변에 반드시 들어가야 하는 핵심 내용을 확인하는 기준입니다. 표현이 정답 예시와 달라도 필요한 사실과 논리를 제대로 포함하면 정답으로 인정합니다. 예를 들어 계산 문제라면 상품 금액 계산, 할인 대상과 배송비 구분, 최종 금액의 정확성을 확인합니다. |
| format_criteria | 사용자가 요구한 출력 형식을 지켰는지 확인하는 기준입니다. JSON 형식, 출력 줄 수, 문장 수, 지정된 항목명 사용, 추가 설명 금지 등이 포함됩니다. 실제 서비스에서는 API 연동이나 자동화 과정에서 형식을 지키지 않은 응답이 오류로 이어질 수 있어 내용과 별도로 확인합니다. |
| obvious_wrong_criteria | 명백하게 잘못된 답을 구분하는 기준입니다. 사실과 반대되는 내용, 잘못된 계산 결과, 근거 없이 단정한 정보 등이 해당합니다. 이 기준을 미리 정해두면 단순한 표현 차이와 실제 오류를 구분하기 쉬워집니다. |

채점은 문항당 내용 2점, 형식 1점으로 총 3점입니다. 형식도 중요하지만, 실무에서는 질문을 정확히 이해하고 올바른 내용을 답하는 것이 우선이라고 판단해 내용 점수의 비중을 더 높였습니다.

### 2. 질문 선정 방향

단순히 얼마나 많은 지식을 아는지보다, 질문을 정확히 이해하는지, 문맥을 따라가는지, 지시한 형식을 지키는지, 정보가 부족할 때 임의로 답을 만들어내지 않는지를 함께 확인할 수 있도록 문항을 구성했습니다.

평가 항목은 다음 6가지입니다.

1. 정확성
2. 핵심 정보 누락 여부
3. 지시·형식 준수
4. 정보 부족 시 대응
5. 일관성
6. 한국어 표현의 품질(문법, 어휘, 자연스러운 표현력, 뉘앙스, 관용어, 높임말)

평가 문항은 3가지 주제, 총 10개로 구성했습니다.

| 주제 | 문항 수 | 세부 항목(해당 문항) |
| --- | --- | --- |
| 정보 해석 및 출력 | 4 | 사실 정보 확인(Q01), 불완전 정보 처리(Q02), 정보 요약(Q04), 오류 정보 처리(Q07) |
| 논리 추론 | 3 | 단순 계산(Q03), 조건에 따른 계산(Q10), 추론(Q06) |
| 한국어 해석 | 3 | 관용 표현 해석(Q05), 중의적 표현 해석(Q08), 완곡 표현 해석·경어체(Q09) |

## Q01. 여러 사실 확인과 구조화

**난이도:** 쉬움 · **카테고리:** 사실 정확성 및 구조화 출력 · **배점:** 총 3점(내용 2, 형식 1)

**질문**

태양계에서 가장 큰 행성과 태양에 가장 가까운 행성은 각각 무엇인가요? 행성 이름은 한국어로 쓰고, "가장큰행성"과 "태양에가장가까운행성" 두 키만 가진 JSON 객체로 답하세요. 코드 블록이나 설명은 붙이지 마세요.

**모범 답안**

{"가장큰행성":"목성","태양에가장가까운행성":"수성"}

**평가 능력:** 복수 사실의 정확성, 핵심 정보 충족, 구조화된 출력, 지시 준수

**채점 기준**

- 내용: 가장 큰 행성을 목성으로, 태양에 가장 가까운 행성을 수성으로 정확히 답함
- 형식: 유효한 JSON 객체, 지정된 두 키만 사용, 행성 이름은 한국어, 코드 블록과 설명 없음(키 순서와 공백은 무관)
- 명백한 오답: 행성을 잘못 답하거나 목성과 수성의 역할을 뒤바꿈

## Q02. 제공된 정보만 사용하고 부족한 정보 인정하기

**난이도:** 보통 · **카테고리:** 근거 기반 응답 및 추측 억제 · **배점:** 총 3점(내용 2, 형식 1)

**질문**

다음 안내문에 있는 정보만 사용하세요.
> 해솔도서관은 화요일부터 일요일까지 오전 9시~오후 6시에 운영하며, 월요일에는 휴관합니다.

아래 세 항목에 답하되, 안내문으로 알 수 없는 항목은 "확인할 수 없음"이라고 쓰세요. 다른 설명 없이 다음 형식으로 세 줄을 출력하세요.
월요일 운영: / 일요일 종료 시각: / 주차 요금:

- 형식: 지정된 세 항목명을 그대로 사용, 세 줄로 출력, 추가 설명 없음
- 명백한 오답: 월요일에 운영한다고 답함 / 일요일 종료 시각을 잘못 답함 / 주차 요금을 무료·유료 또는 특정 금액으로 임의로 단정함

## Q03. 간단한 계산과 적용 순서

**난이도:** 보통 · **카테고리:** 산술 계산 및 조건 적용 · **배점:** 총 3점(내용 2, 형식 1)

**질문**

한 권에 2,000원인 공책 3권을 삽니다. 상품 금액에만 10% 할인을 적용하고, 할인되지 않는 배송비 1,500원을 더합니다. 최종 결제금액을 계산하세요. 첫 줄은 "계산식:", 둘째 줄은 "결제금액:"으로 시작하고, 두 줄만 출력하세요.

**모범 답안**

계산식: 2,000 × 3 × 0.9 + 1,500 = 6,900
결제금액: 6,900원

**평가 능력:** 산술 계산, 조건 적용, 계산과 결론의 일관성

**채점 기준**

- 내용: 공책 3권의 상품 금액을 6,000원으로 계산 / 상품 금액에만 10% 할인을 적용해 5,400원으로 계산 / 배송비 1,500원은 할인하지 않음 / 최종 결제금액을 6,900원으로 계산(동등한 계산식은 인정)
- 형식: 정확히 두 줄로 출력, 첫 줄이 "계산식:"으로 시작, 둘째 줄이 "결제금액:"으로 시작, 최종 결제금액에 원 단위 표시
- 명백한 오답: 배송비까지 할인함 / 최종 결제금액을 잘못 계산함 / 계산식과 최종 금액이 서로 모순됨

## Q04. 필요한 정보만 남기는 문맥 요약

**난이도:** 보통 · **카테고리:** 한국어 요약 및 핵심 정보 선별 · **배점:** 총 3점(내용 2, 형식 1)

**질문**

다음 안내를 행사 내용·장소·일시·취소 조건만 담아 존댓말 한 문장으로 요약하세요. 준비물 정보와 별도 설명은 제외하세요.

> "토요일 오전 10시에 중앙공원에서 쓰레기 줍기 행사를 진행합니다. 장갑은 현장에서 제공합니다. 마실 물은 각자 준비하세요. 비가 오면 행사는 취소됩니다."

**모범 답안**

토요일 오전 10시 중앙공원에서 쓰레기 줍기 행사가 열리며, 비가 오면 취소됩니다.

**평가 능력:** 핵심 정보 선별, 요약의 충실성, 자연스러운 한국어 표현, 불필요한 정보 제외

**채점 기준**

- 내용: 쓰레기 줍기 행사 포함 / 장소인 중앙공원 포함 / 토요일 오전 10시 포함 / 비가 오면 취소된다는 조건 포함
- 형식: 완결된 존댓말 한 문장, 장갑이나 마실 물 등 준비물 정보 제외, 별도 설명 없음
- 명백한 오답: 시간이나 장소를 바꿈 / 우천 시 연기 또는 실내 진행이라고 답함 / 안내문에 없는 날짜·참가비 등의 정보를 만들어 넣음

## Q05. 한국어 속담의 문맥상 의미

**난이도:** 보통 · **카테고리:** 한국어 비유 및 문맥 이해 · **배점:** 총 3점(내용 2, 형식 1)

**질문**

민지는 이미 검토한 보고서를 제출하기 전에 수치를 한 번 더 확인했습니다. 동료는 이를 보고 "돌다리도 두들겨 보고 건너라더니"라고 말했습니다. 이 속담이 이 상황에서 뜻하는 바를 민지의 행동과 연결해 존댓말 한 문장으로 설명하세요.

**모범 답안**

이미 검토한 보고서라도 실수가 없는지 수치를 다시 확인하듯, 확실해 보이는 일도 신중하게 점검한다는 뜻입니다.

**평가 능력:** 비유적 표현 이해, 문맥 해석, 한국어 설명, 행동과 의미 연결

**채점 기준**

- 내용: 확실하거나 안전해 보이는 일도 다시 확인한다는 의미를 설명 / 그 의미를 민지가 보고서 수치를 재확인한 행동과 연결
- 형식: 완결된 존댓말 한 문장으로 답함
- 명백한 오답: 실제 돌다리를 점검하는 이야기로만 해석 / 재확인이 불필요하다는 의미로 설명 / 빨리 행동하라는 의미로 설명

## Q06. 조건 추론과 역방향 추론 방지

**난이도:** 추론 필요 · **카테고리:** 논리 추론 · **배점:** 총 3점(내용 2, 형식 1)

**질문**

다음 정보만 사용하세요. 모든 정회원은 출입카드가 있습니다. 지수는 정회원입니다. 민수는 출입카드가 있습니다.

A. 지수는 출입카드가 있다.
B. 민수는 정회원이다.
C. 지수는 출입카드가 없다.

각 문장이 반드시 참이면 "참", 반드시 거짓이면 "거짓", 참과 거짓이 모두 가능하면 "판단불가"로 분류하세요. 설명 없이 "A=분류", "B=분류", "C=분류" 형식으로 세 줄을 쓰세요.

**모범 답안**

A=참
B=판단불가
C=거짓

**평가 능력:** 조건 추론, 논리적 일관성, 역방향 추론 방지, 불확실한 결론의 보류

**채점 기준**

- 내용: 정회원인 지수에게 출입카드가 있음을 올바르게 추론 / 출입카드가 있다는 사실만으로 민수가 정회원이라고 역추론하지 않음 / 지수에게 출입카드가 없다는 명제를 거짓으로 분류
- 형식: 지정된 A, B, C 순서로 세 줄 작성, 분류에는 참/거짓/판단불가만 사용, 추가 설명 없음
- 명백한 오답: 민수가 반드시 정회원이라고 결론 / 민수가 반드시 비회원이라고 결론 / 지수에게 출입카드가 없을 수도 있다고 판단

## Q07. 잘못된 전제 바로잡기

**난이도:** 보통 · **카테고리:** 사실 정확성 및 전제 교정 · **배점:** 총 3점(내용 2, 형식 1)

**질문**

펭귄은 포유류인데 어떻게 알을 낳나요? 질문에 잘못된 전제가 있으면 바로잡고, 펭귄의 정확한 동물 분류와 번식 방식을 존댓말 두 문장으로 답하세요.

**모범 답안**

펭귄은 포유류가 아니라 조류입니다. 펭귄은 알을 낳아 번식합니다.

**평가 능력:** 사실 정확성, 잘못된 전제 교정, 일관된 설명

**채점 기준**

- 내용: 펭귄이 포유류라는 전제를 명시적으로 바로잡음 / 펭귄을 조류로 정확히 분류 / 펭귄이 알을 낳아 번식한다고 설명
- 형식: 완결된 존댓말 두 문장으로 답함
- 명백한 오답: 펭귄을 알을 낳는 포유류의 예외라고 설명 / 펭귄이 포유류라는 전제를 그대로 받아들임 / 펭귄이 새끼를 출산한다고 답함

## Q08. 다의어 중의성 해석

## Q09. 완곡한 거절 신호 해석

## Q10. 위약금 산정 기준 해석

**난이도:** 보통~어려움 · **카테고리:** 정보 부족 대응 및 조건 구분 · **배점:** 총 3점(내용 2, 형식 1)

**질문**

계약 해지 시 위약금은 잔여 기간에 해당하는 금액의 10%인가요, 아니면 전체 계약금의 10%인가요?

**모범 답안**

두 방식은 계산 기준이 다르며, 잔여 기간 기준이면 남은 계약 기간에 해당하는 금액의 10%를 계산하고 전체 계약금 기준이면 전체 계약금의 10%를 계산합니다. 실제 적용 기준은 계약서의 위약금 조항을 확인해야 합니다.

**평가 능력:** 조건 구분, 핵심 정보 충족, 정보 부족 시 대응, 근거 없는 단정 방지

**채점 기준**

- 내용: 잔여 기간에 해당하는 금액의 10%와 전체 계약금의 10%가 서로 다른 계산 기준임을 설명 / 잔여 기간 기준의 의미를 올바르게 설명 / 전체 계약금 기준의 의미를 올바르게 설명 / 실제 어떤 기준이 적용되는지는 제공된 정보만으로 확정하지 않음 / 계약서 조항 등 추가 근거 확인이 필요하다고 안내
- 형식: 두 기준을 모두 언급, 자연스러운 존댓말로 답함
- 명백한 오답: 실제 위약금 기준을 하나로 근거 없이 단정 / 잔여 기간 기준과 전체 계약금 기준의 의미를 뒤바꿈 / 제공되지 않은 계약 조건이나 금액을 임의로 만들어 냄
