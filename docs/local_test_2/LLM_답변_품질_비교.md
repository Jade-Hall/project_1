# LLM 답변 품질 비교

평가 대상: 모델 3개 × 문항 10개 × 실행 2회 = 60개 응답. 각 문항의 채점 기준(content_checkpoints, format_criteria, obvious_wrong_criteria, scoring)은 결과 JSON에 문항별로 내장되어 있으며, 이 기준에 따라 응답 하나하나를 직접 채점했습니다.

원본: test3.zip · reports/test/*.json (6개)

---

## 채점 규칙

문항마다 기준이 다르므로, 모든 문항에 공통으로 적용한 판정 규칙만 밝혀 둡니다.

| 구분 | 규칙 |
|---|---|
| content 2점 | content_checkpoints를 모두 충족하고 obvious_wrong_criteria에 해당하지 않음 |
| content 1점 | 체크포인트 일부만 충족 |
| content 0점 | 체크포인트를 사실상 충족하지 못함 |
| obvious_wrong 해당 시 | content를 최대 1점으로 제한 (충족 체크포인트가 없으면 0점) |
| format 1점 | format_criteria를 모두 충족 |
| format 0점 | format_criteria 중 하나라도 위반 |
| 특수 토큰 노출 | 템플릿 토큰이 그대로 남으면 형식 위반으로 처리 |

questions.json에 해당하는 항목이 없는 부분으로는 감점하지 않았습니다. 속도·VRAM 등 성능 수치는 채점에 일절 사용하지 않았습니다.
